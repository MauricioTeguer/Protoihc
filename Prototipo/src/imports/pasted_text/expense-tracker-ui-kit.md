Design a complete mobile UI kit and set of screens for a personal expense tracking mobile application.
The design must follow modern mobile UX best practices, using a clean, minimalist, mobile-first interface with clear visual hierarchy, consistent spacing, rounded components and accessible touch targets.
Create a consistent design system first, then generate all application screens using that system.
The design system should include:
• A modern fintech color palette (primary green or blue, neutral background, soft accent colors)
 • Typography hierarchy (title, subtitle, body text, labels)
 • Rounded primary buttons
 • Secondary buttons
 • Input fields with icons
 • Card components for expense items
 • Bottom navigation bar
 • Consistent spacing grid for mobile layout
 • Icons for categories and actions
Maintain consistent colors, typography, layout and components across all screens.
The interface should be simple, intuitive, and designed for everyday use, allowing users to quickly register and visualize their expenses.
